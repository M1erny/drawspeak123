# Audyt UX — prototyp v2 (HTML)

Plik: `docs/reviews/ux-grok.md`. Kandydat: `prototype/index.html`, SHA256 `2c69cfa0e2abce2e5943ce1f84f98285b2a4df9e94df79b1184ee83a4f0b2598` (zgodny z briefem).

**Kto i po co.** Jedna osoba, w skupieniu przerywanym kodem, ma oznaczyć UI, porównać `Now` / `Proposal A` / `Proposal B` i zebrać jedną paczkę albo lokalny stash. Sukces: „przekazałem spójny zestaw i nie zgubiłem punktu odniesienia”. Celu konwersji nie ma. Auto-start głosu po **nowym** regionie zostaje domyślnie włączony; ta decyzja jest ważniejsza niż twardy default skilla.

**Werdykt.** Spoczynek canvasu jest czytelny: trzy kolumny, wątek w nagłówku, jawne „voice simulated”. Pętla region → głos → paczka psuje się w kontroli i na końcu. Krzywa: wejście **+1** → trzy widoki **+1** (najlepszy moment, zrzuty spoczynku) → auto-start demo **+1** → panel nagrania **−1** → niejawny fixture albo cudzy Undo **−2** (najgorszy) → Stop i własna edycja **+1** → stash **+1** → `Simulate Send` i sam toast **0**. Koniec nie utrwala, co się stało. Szczyt zaprojektowany w specyfikacji (jedna paczka) w prototypie nie domyka się ekranem.

**Scorecard.** Information **1/3** · Meaning **2/3** · Time **1/3** · Memory **1/3** · Ethics **PASS**.

Etyka auto-startu (**Default Bias**, technika ⚠): przejście. Użytkownik tego wymaga; przełącznik w Canvas Actions jest tak samo łatwy jak włączenie (`prototype/index.html:35`, `:48`, `:115`); dotyczy tylko nowych regionów; strzałka i freehand nie startują głosu (`:107`); otwarcie starej uwagi nie wznawia (`:100`). To nie jest ukryta zgoda na mikrofon: badge, timer i pomoc mówią, że audio nie istnieje (`:22`, `:37`, zrzut nagrania). Nie rekomenduję default OFF. FAIL byłby dopiero wtedy, gdyby fixture wszedł do paczki jako słowa użytkownika bez okazji do korekty — stąd finding 2, nadal przy auto-starcie ON.

## Co zachować

Trzy kolumny w jednym świecie, osobne wersje A i B, `Now` jako baseline, pan/zoom i Fit All (`:93–94`; zrzuty spoczynku). Region domyślnie startuje demo tylko dla nowego okręgu; palec panuje, dopóki „Draw with finger” jest wyłączone (`:105`). Nagranie niesie `canvasId`/`noteId` i przy zmianie canvasu ląduje na pierwotnej uwadze (`:98`, `:101–102`) — poprawić treść zapisu, nie to wiązanie. Stash i batch odrzucają obcy canvas (`:52–54`). `localStorage` v2 trzyma ustawienia, uwagi, stash i kamerę (`:44`, `:55`); bajty importu są tylko w `sessionImages` (`:72`, `:132`), a brak obrazu blokuje nowe kreski (`:105`). Badge i „no microphone access” są widoczne na zrzutach. Symulacja nie udaje Tailscale.

## Szybkie vs strukturalne

Szybkie: CSS `[hidden]`, fixture wyłącznie po Stop, słowo „Notes”, numer pustej uwagi w błędzie, odsunięcie Delete. Strukturalne: kamera przy otwartym panelu, stos Undo, miniatura w paczce, pasek uwag innej iteracji. Poza zakresem: promocja baseline, prawdziwy mikrofon, T3, Tailscale.

## Walidacja (bez konwersji)

Na 1194 i 728: nowy region → auto-start → Stop → edycja → Save → Stash, oraz X w trakcie nagrania i Undo po skasowaniu uwagi, która nie jest ostatnia. Liczyć uwagi z tekstem bez Stop, trafienie snapshotu w paczce i czy B widać przy otwartym komentarzu. Przerywane próby zostawić w wyniku (**Survivorship Bias**). Osobno, dopiero na urządzeniu: Pencil, VoiceOver, kontrast, zgoda mikrofonu.
