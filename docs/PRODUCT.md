# Specyfikacja produktu

Aktualnym źródłem wymagań jest [PRD — Review Canvas](PRD.md), a decyzje są zapisane w [rejestrze ADR](adr/README.md).

Wcześniejszy dokument łączący etapy v1–v3 zachowano jako [archiwum PRODUCT-v1-v3](archive/PRODUCT-v1-v3.md). Nie opisuje on najnowszego przyjętego flow.

Wiążący przebieg: Feedback (N) → podgląd → Send to Agent / Save Draft → potwierdzenie. Uwagi zapisują się automatycznie; osobne Save Comment nie należy do docelowego UX.

Stan aktualnego kodu i brakujące funkcje są oddzielnie opisane w PRD, sekcja 12. Utworzenie dokumentacji nie wdraża nowego flow w prototypie.
